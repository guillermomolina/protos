# Protos Support and Community Channels

Protos is an experimental programming-language project under active
development. Community questions and feedback are welcome.

## Questions, ideas, and design discussion

Use [GitHub Discussions](https://github.com/guillermomolina/protos/discussions)
for:

- questions about using or understanding Protos;
- exploratory language or library ideas;
- design discussion that is not yet actionable work;
- feedback about the project direction;
- introductions and contributor questions; and
- things you have built or experimented with using Protos.

If you are unsure where something belongs, start in Discussions.

## Bugs and actionable work

Use [GitHub Issues](https://github.com/guillermomolina/protos/issues) for
reproducible bugs, concrete documentation problems, and scoped actionable work.

Please use the available issue forms when they fit. A design idea does not need
to become an issue until there is a sufficiently concrete problem or outcome to
track.

## Contributions

See [CONTRIBUTING.md](CONTRIBUTING.md) before preparing a substantial change.
AI-assisted and fully AI-generated contributions are welcome under the same
review and evidence standards as other contributions.

## Security

Do not publish vulnerability details in an ordinary public issue. Follow
[SECURITY.md](SECURITY.md).

## Support expectations

Protos is currently maintained as an experimental open-source project. Support
is provided on a best-effort basis; there is no response-time or production
support guarantee.

Clear reproductions, small examples, relevant environment information, and links
to the applicable specification or documentation make questions much easier to
answer.
