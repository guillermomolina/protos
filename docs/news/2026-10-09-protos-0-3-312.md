# Protos v0.3.312 Released — Expanded Standard Library, Java Interoperability and Native Linux

**October 9, 2026**

Protos **0.3.312** is now available as a public prerelease. It grows the
Standard Library, adds the first Java interoperability surfaces, extends the
bundled developer tooling, and ships again as a self-contained Native archive
for Linux x86_64 alongside the portable JVM distribution.

## What's New

### Standard Library

New `std:` modules, written in Protos and shipped in both distributions:

- **Regular expressions** — `std:regex/Regex`: portable, linear-time matching,
  captures, replacement, and splitting.
- **Date and time** — `std:datetime/*`: civil dates and times, instants, fixed
  offsets, durations, periods, ISO 8601 and RFC 3339 text.
- **Structured logging** — `std:logging/*`: explicit loggers, levels,
  structured fields, text/JSON/colored formatting, and sinks.
- **Styled text and ANSI** — `std:text/*`: styled text, ANSI rendering,
  color-mode policy, and encoding helpers.
- **Semantic versioning** — `std:semver/SemVer`: strict SemVer 2.0.0 parsing,
  formatting, equality, and precedence.
- **`std:interop`** — explicit `invoke`, `instantiate`, `readMember`, and
  `writeMember` operations on foreign values.

Importing a module grants no authority: a module that writes text, reads a
time, or touches a file does so only through a value you pass to it. See the
[Standard Library guides](../guide/library/README.md).

### Java interoperability

- **GraalVM Polyglot embedding** — a Java application can create a standard
  Polyglot `Context`, evaluate Protos source, and exchange values
  ([guide](../guide/embedding/java.md)).
- **Application-defined `app:` modules** — an embedding host can install a
  fixed catalog of Protos source modules that guest code imports as
  `import("app:...")` ([guide](../guide/embedding/application-modules.md)).
- **Foreign-provider infrastructure** — a public provider SPI lets a provider
  JAR own an import scheme and expose foreign modules and values under the
  specification's conversion, identity, and error rules
  ([guide](../guide/interop/README.md)).
- **The `java:` namespace** — the Java provider fixture now owns the `java:`
  scheme (`import("java:math")`, `import("java:date")`); `jdk:` is not an alias
  ([guide](../guide/interop/java-provider.md)).

These capabilities have deliberate limits in this release:

- Java embedding and `app:` modules run on the **portable JVM** runtime only;
  there is no Native Image embedding host.
- External providers are loaded only by the **portable JVM** CLI, with
  `protos --foreign-provider-path <jars>`. The Native CLI cannot load them, and
  a standard Polyglot `Context` has no option to register them.
- No provider ships inside the distribution: `java:` is a fixture you build
  and pass explicitly, not a universal bridge to arbitrary Java APIs.
- Synchronous callbacks do not cross the public provider SPI.

### Developer tooling

- **CLI and Package Tool** — `protos` runs programs and drives `format`,
  `lint`, `test`, `package`, the REPL, the language server, and the debug
  adapter ([CLI guide](../guide/tools/cli.md),
  [Package Tool](../guide/tools/package-tool.md)).
- **Test Tool** — `protos test` runs the bundled Test Tool
  ([guide](../guide/tools/test-tool.md)).
- **Language server** — a static LSP server with diagnostics, formatting,
  document and workspace symbols, go to definition, find references, hover,
  completion, and signature help
  ([guide](../guide/tools/language-server.md)). It does not provide code
  actions, quick fixes, or rename.
- **Static lint** — `protos lint` reports parser errors and lint warnings
  without executing code, as text or JSON, and can fail on warnings; the
  language server publishes the same warnings.

### Runtime

This release continues the pay-as-you-grow optimization work, including
pay-as-you-grow scalar lowering for local assignment (PERF036-A) and other
internal runtime improvements. Observable program behavior is unchanged, and
this announcement makes no performance-figure claims.

### Native distribution

- **Linux x86_64**, dynamic **glibc 2.39** or newer.
- **No external JDK**, GraalVM, or Maven needed after extraction.
- **Guest JIT disabled** (PLAT045): guest Protos code runs interpreter-only in
  the Native executable while
  [oracle/graal#14579](https://github.com/oracle/graal/issues/14579) remains
  unresolved. Program behavior is unchanged; long-running programs are slower
  than on the portable JVM.
- `std:regex` Unicode data is now embedded, so `import("std:regex/Regex")`
  works in Native too.
- Release validation: the Native test suite passed with **2,581 tests PASS,
  0 FAIL** (DIST015).

No Native support is claimed for macOS, Windows, AArch64, musl, or glibc older
than 2.39.

## Downloads

Download from the
[Protos 0.3.312 GitHub Release](https://github.com/guillermomolina/protos/releases/tag/v0.3.312).
Each archive has an adjacent `.sha256` file.

| Archive | Use it for | Requirements |
|---|---|---|
| `protos-0.3.312-native-linux-x86_64.zip` | Recommended first run | Linux x86_64, glibc 2.39+; no external Java |
| `protos-0.3.312-posix-jvm.zip` | Compatibility fallback, Java embedding, external providers, guest JIT | GraalVM Community 25.4.4.1.1 / JDK 25.0.4.1.1 |

```sh
curl -LO https://github.com/guillermomolina/protos/releases/download/v0.3.312/protos-0.3.312-native-linux-x86_64.zip
curl -LO https://github.com/guillermomolina/protos/releases/download/v0.3.312/protos-0.3.312-native-linux-x86_64.zip.sha256
sha256sum -c protos-0.3.312-native-linux-x86_64.zip.sha256
unzip protos-0.3.312-native-linux-x86_64.zip
./protos-0.3.312-native-linux-x86_64/bin/protos -e 'print("Hello, Protos!")'
```

The [Try Protos guide](../guide/00-try-protos.md) covers both archives and the
Dev Container.

## Prerelease status

Protos 0.3.312 is an experimental **prerelease**, and Protos/Core v0.1 remains
a draft specification. It is not a claim of stable-language status or broad
platform support.
