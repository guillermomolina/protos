# Language decision records

This role contains durable non-normative `Dxxx` records of language or
specification decisions. These files record the decision process and rationale;
they do not replace the normative specification under `spec/`.

New unambiguous `Dxxx` decision records use this directory. Existing flat `Dxxx`
records remain at their current paths until the DOC002 decision-migration slice
moves them with link and authority checks.
