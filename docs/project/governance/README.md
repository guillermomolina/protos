# Project governance and rationale

`governance/` contains maintained repository/project policy and rationale that
belongs to durable project documentation but does not need an invented formal
work family. Classification alone must not create identifiers such as `LICxxx`.

This role does not absorb root files whose conventional discoverability belongs
at repository root, such as `LICENSE.TXT`, `CONTRIBUTING.md`, `SECURITY.md`, or
`AGENTS.md`. Existing flat governance records migrate only in bounded DOC002
slices.

## Maintained records

- [`LICENSING_RATIONALE.md`](LICENSING_RATIONALE.md) — non-normative rationale
  for the project's APL-1.0 licensing choice; `LICENSE.TXT` remains authoritative.
- [`STANDARD_LIBRARY_NAMING.md`](STANDARD_LIBRARY_NAMING.md) — non-normative
  distribution/host-resolution naming policy for official Standard Library
  modules.
