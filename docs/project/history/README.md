# Historical project snapshots

`history/` contains retired or superseded repository snapshots that remain useful
as historical evidence but must not look like current live project state.

Moving a historical file does not reactivate or reinterpret it. Existing legacy
history paths are migrated only in bounded DOC002 slices with reference checks.

## Retained snapshots

- [`OPEN_TASKS.md`](OPEN_TASKS.md) — frozen pre-GitHub-native backlog snapshot
  retained only as historical/reconciliation evidence. GitHub Issues and the
  Protos Development Project own live work state.
